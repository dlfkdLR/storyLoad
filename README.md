# 스토리로드 (StoryRoad)

> 여행지에 직접 방문해야 콘텐츠가 열리는 위치 기반 스탬프·오디오 SNS.
> 현지인의 이야기와 여행자의 추억을 음성·사진·글로 기록하고 수집하는 디지털 여행 다이어리.

## 실행 방법

1. `StoryRoad.xcodeproj`를 Xcode로 엽니다 (Xcode 16 이상, iOS 17.0+)
2. 시뮬레이터(iPhone)를 선택하고 **⌘R**로 실행합니다
3. 위치 권한을 "앱을 사용하는 동안 허용"으로 선택합니다

### 위치 기반 기능 시연 (시뮬레이터)

- Xcode 메뉴 **Features > Location > Custom Location…** 에서 좌표를 입력하면 해당 지역 도착 배너가 뜹니다
  - 경주: `35.8562, 129.2247` / 포항: `36.0190, 129.3435` / 안동: `36.5684, 128.7294`
- 또는 앱 우측 상단 ✨ 버튼의 **데모 모드**(기본 켜짐)를 사용하면 방문 없이도 잠금 해제 가능 → 심사용

## 핵심 기능

| 기능 | 구현 |
|---|---|
| 위치 기반 잠금 해제 | CoreLocation으로 지역 반경 도착 판정. 방문 전엔 티저(대략적 소개)만 공개 |
| 행정구역 지도 | 경북 22개 시·군 + 대구, 총 23개 지역을 경계 폴리곤(GeoJSON)으로 표시 — 미방문은 연한 회색, 방문한 곳은 지역 색 + 그곳에서 찍은 사진 썸네일 |
| 오디오 스토리 | 타사용자 스토리 청취 + 내 이야기 직접 녹음(AVAudioRecorder) → 피드에 게시 |
| 스탬프 (도장깨기) | 방문한 지역을 스탬프로 수집, 진행률 표시 |
| 단방향 SNS 피드 | 사진·음성·좋아요·댓글이 있는 SNS 카드. 잠긴 지역 게시물은 사진 흐림 + 오디오 비공개 |
| 지역 여행자 피드 | 해제된 지역 상세에서 다른 사람들이 올린 사진·음성 게시물 열람 |
| 나만 보는 추억 | 사진(PhotosPicker)·글·음성 메모를 지역별 비공개 다이어리로 저장 |
| 현지인 이야기 | 해당 지역 주민이 올린 동네 꿀팁 노출 |

## 기술 스택

- **SwiftUI** (iOS 17+) — 전체 UI
- **MapKit** — 경북 22개 시·군 + 대구 행정구역 경계 폴리곤(통계청 GeoJSON) 및 사진/스탬프 마커
- **CoreLocation** — 지역 도착 판정 및 잠금 해제
- **AVFoundation** — 음성 녹음·재생, 타사용자 스토리는 음성 합성(TTS)으로 데모
- 로컬 JSON 저장 — 스탬프·추억·내 녹음 영구 보존 (서버 없이 동작)

## 폴더 구조

```
StoryRoad/
├── StoryRoadApp.swift        # 앱 진입점
├── Models/                   # 데이터 모델 + 23개 지역(경북 전체 + 대구) 샘플 데이터
├── Services/                 # AppStore(상태/저장), 위치, 녹음, 재생, 경계 로더
├── Resources/                # RegionBoundaries.geojson (시·군 경계)
└── Views/
    ├── Map/                  # 지도 탭 (스탬프 마커, 도착 배너)
    ├── Region/               # 지역 상세 (잠금/해제 상태)
    ├── Feed/                 # 단방향 SNS 피드
    ├── Stamps/               # 스탬프 수집 현황
    ├── Memories/             # 비공개 추억 다이어리
    └── Components/           # 오디오 행, 녹음 시트 등
```
